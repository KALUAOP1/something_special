# 🎂 Something Special - Cute Malkin's 19th Birthday Celebration 👑💖✨

A magical, interactive multi-step birthday celebration web application created with love for Cute Malkin.

---

## ✨ Features

- 🌟 **Step 1: Welcome & Birthday Reveal**: Dynamic name reveal, countdown banner, background music & confetti.
- 🎂 **Step 2: Interactive Cake Cutting**: Realistic 3D cake, blowable candles, fireworks pop-up banner, and celebratory cheer.
- 💌 **Step 3: Reasons You Are Special**: Curated sweet GIF cards with interactive love reactions and secret notes.
- 🎁 **Step 4: Mystery Birthday Gifts**: Interactive 3D gift boxes that unwrap to reveal surprise birthday videos.
- 🖼️ **Step 5: Memory Scrapbook & Clothesline Wall**:
  - Filterable polaroid memories strung on twinkling fairy lights.
  - Fullscreen lightbox viewer for every memory.
  - **🍿 Play Cinematic Birthday Story Reel**: Fullscreen Ken Burns photo slideshow with synchronized romantic music (`Unki Tareef Mein Kahein Kya`).
- 🏮 **Step 6: Midnight Wishing Sky**:
  - Interactive starry canvas with floating lanterns.
  - Paper folding into flying lantern ascension animation.
  - Secret wish recorder (`save_wish.php`) that preserves wishes privately in `README_SECRET_WISHES.md`.
- 📜 **Step 7: Heartfelt Birthday Letter**: Romantic, heartfelt letter with editable parchment paper.

---

## 🚀 How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/KALUAOP1/something_special.git
   ```
2. Open `index.html` directly in any modern browser, or run a local server:
   ```bash
   python -m http.server 8000
   ```
3. Navigate to `http://localhost:8000`.
